# js-plugin-ui

JS-only local plugin example that exposes a UI layout descriptor.

- Capabilities: `plugins`, `plugin.org.example.sample_ui`, `ui`
- Expected provider: local JS-only plugin manager plus Activity-owned UI bridge
- Packaged support: supported only for already-packaged local plugin files
- Security limitations: no plugin download, native archive, marketplace, or Android object provider expansion

Expected output is listed in `expected-output.txt`.
