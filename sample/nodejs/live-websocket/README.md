# live-websocket

Controlled WebSocket example using the AutoJs6 `websocket` module.

- Capabilities: `network`
- Expected provider: Android controlled WebSocket provider
- Packaged support: not enabled by default; packaged apps need explicit network capability and INTERNET mapping
- Security limitations: raw socket modules remain denied; connection, queue, and message-size limits apply

Expected output is listed in `expected-output.txt`.
