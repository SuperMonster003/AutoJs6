## Remaining acceptance boundary

P1.5/P1.6 implementation and the above checks are complete. The original P1
cross-process attach -> model -> compact observation -> registered execution ->
detach scenario still needs P7's independent Agent conformance APK. The public
JavaScript result/context check remains P5. Local Binder tests, real P0 INFO
probes and individual bridge tests do not replace that combined scenario.
P1 as a whole is therefore not marked fully accepted; the next original
implementation step is P2.1 (tool catalog, handlers and risk policy).
