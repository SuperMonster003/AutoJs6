# AI Agent P2.1 host grant correction (2026-09-23)

The plugin's first tool catalog maps `ui_press_key` values `notifications` and
`quick_settings` to the existing `keys.notifications` and `keys.quickSettings`
bridge operations. The initial Agent grant omitted both operations and removed
the required `keys` token, so these declared actions would always be denied.

The grant now admits these two operations and their token. The method allowlist
continues to reject all other `keys` operations. This changes no MCP grants,
public script APIs, AIDL transactions or minimum host build (6.8.0 / 5285).
