## Optional OCR discovery

The shared V1 broker info has an optional String array, availableOptionalMethods.
Missing means no optional method advertised. The current entry is
accessibility.readScreenText, included only when the method and all three
permissions are granted and OcrPluginHost.availableEngines finds an installed,
authorized, enabled, compatible candidate. Discovery neither binds an OCR
service nor captures the screen. Runtime OCR failures remain tool failures.
Availability is a snapshot, independently checked from the grant, and is refreshed
by the Agent at each task start. A destroyed broker advertises no optional method.
No AIDL transaction or contract version changed.
