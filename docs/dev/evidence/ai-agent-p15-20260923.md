# AI Agent P1.5 host entry evidence (2026-09-23)

This records the drawer, plugin-center registration and attachment entry work.
The plugin still exposes its P0 placeholder Binder until P2.5. Enabling it in
the plugin center and opening its launcher do not imply task execution support.

## Delivered behavior

- The drawer displays AI Agent, attachment state, and attached running/queued
  counts. Its manager action opens the plugin's existing explicit launcher.
  State-specific installation, activation, enablement, authorization, trust,
  compatibility and failure guides have resources in all 11 host directories.
- Plugin-center service discovery, engine/action mapping, metadata probe and
  settings entry recognize the official Agent package. Package-manager-only
  snapshots identify the engine before INFO is loaded, preserving default-off
  behavior in the first frame. Existing explicit enable records and the shared
  official fresh-install authorization policy retain their established meaning.
- Management probes the existing INFO service. Runtime attachment separately
  checks the dedicated Agent interface and contract; the placeholder cannot pass
  runtime validation merely because its management metadata is valid.
- The process-owned connection survives drawer disposal and serializes connect,
  refresh and detach. Host startup restores a remembered connection only; no run
  is started or replayed. Plugin disable/removal/trust changes refresh admission.
- The exported attachment receiver requires PLUGIN permission and the existing
  immutable plugin-created PendingIntent identity proof. The existing main
  activity accepts the same authenticated foreground request and consumes its
  extras. Unavailable background requests retain a guide for the resumed host UI.

The P1.5 phrase "boot / host startup" conflicts with fixed decisions D15/D16.
The implementation follows those decisions: **host process startup only, no boot
receiver and no automatic task restart**. D41's plugin-side 500 ms fallback
policy still awaits P7 device compatibility evidence.
