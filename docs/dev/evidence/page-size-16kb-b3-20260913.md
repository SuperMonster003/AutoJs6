## API 契约

- AutoJs6 6.8.0 提供 `device.pageSize` 与 `$device.pageSize`, JavaScript 类型为 `number`, 单位为字节.
- getter 复用 `NativePageSize.current()`, 通过 `Os.sysconf(OsConstants._SC_PAGESIZE)` 查询并在进程内缓存. 查询失败会抛出异常, 不以固定的 4096 代替.
- 属性显式使用 `READONLY | PERMANENT`, 不可赋值, 删除或改写为其他值; 不需要额外权限或插件.
- 页大小是当前系统的运行环境信息. APK / 原生库是否兼容该环境仍由对齐门禁与设备运行验证判定.
- 实现位于 `app/src/main/java/org/autojs/autojs/runtime/api/augment/device/Device.kt`; 未修改 `com/stardust/**`.

Android 平台查询依据: [Support 16 KB page sizes](https://developer.android.com/guide/practices/page-sizes), [Os.sysconf](https://developer.android.com/reference/android/system/Os#sysconf(int)).
