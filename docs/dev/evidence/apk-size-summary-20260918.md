- dex: 26.18 -> 18.85 MiB (-7.33 MiB), 方法数 433,419 -> 304,906 (-128,513); 剩余大头是运行时 R8 (`com.android.tools.r8`, 约 6.59 MiB 归属 DEX, 受 D5 门禁的 P5.2) 与 Rhino / Kotlin / OkHttp 等必需依赖.
- assets: 1.55 -> 0.76 MiB, 全部来自 P6.5 的版本历史剪除 (`assets/doc` 0.96 -> 0.16 MiB).
- res: 2.55 -> 2.00 MiB, P6.1 / P6.4 去掉的库资源约 0.09 MiB, P6.6 的 WebP 转换 0.47 MiB.
- lib 不变 (1.53 MiB, universal 含四个 ABI); `resources.arsc` 只随资源条目数微降.

## 3. 关闭为记录项 / 受门禁的项

| 项 | 结论 | 依据 |
| --- | --- | --- |
| P6.3 joda-time 时区表 (0.11 MiB) | 保留 | 只有 no-tzdb + 自有 ZoneRules 桥接才能去掉, 收益不抵风险 (6869ef207) |
| P6.7 minify 实验 | 取消 | D10: release 不启用 minify |
| P6.8 `com.stardust` 兼容包 (0.43 MiB) | 保留 | D16 |
| P5.2 运行时 R8 (约 5.5 MiB) | 门禁 D5 | DEX 编译器插件晋级默认路径, 且 `loadAar` / `defineClass` 有非 R8 方案 |
| P5.3 旧版 dx 1.7.0 (约 0.17 MiB) | 门禁 Q10 | API 24 / 25 唯一的 class -> dex 转换器, 建议保持现状 |
| Q11 `res/anim` AOSP 动画集 (源文件约 0.33 MiB) | 待拍板 | 脚本 UI 可按名字引用 `@anim/`, 但无文档化清单 (P6.6) |
