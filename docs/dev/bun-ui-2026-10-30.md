## Runtime behavior

The Bun host client (Bun Runtime d632532 - 37a5f5c) carries the Node.js Runtime's shared UI factory (`portable-ui-compose.js` of Node 8fc9c801). The Node side's `sync-ui-compose.js` writes it into the client (Node 4895ff4d keeps it out of the client's generated sections), and the Bun side's `tools/host-client/sync-ui-family.mjs` generates the RuntimeUi / RuntimeCompose / RuntimeFloaty / RuntimeWeb / RuntimeTerminal / RuntimeConsole declarations. `--check` keeps both equal to Node.

- Grants. The client maps the Node capabilities the shared factory names to Bun grants. A call whose grants are off rejects NOT_GRANTED with `missingCapabilities` before reaching the host (Q90).
  - ui.layout: the content view and window members (Q164 (a)), the injectable WebView and client (Q174 (a)).
  - floaty.control: floaty.window, closeAll, the overlay permission queries, and a floaty window's controls (Q173 (a)). When ui.layout is off, the view routes of a floaty window (findView, view properties, inflate) also go through floaty.control.
  - floaty.raw for rawWindow and floaty.touch for setTouchable; clipboard.control for floaty.getClip.
  - terminal.control (Q3 (a), not implied by shell.control): every terminal call is a long-wait task of BunAutomationBridge, the timeout clamped to 905 s. Host failures stay TerminalError; a NOT_GRANTED with `missingCapabilities` is not wrapped (Node 370f4088).
  - console.control: the window controls, configure, console.build's show and rawInput. ui.toast: toast.dismissAll. ui.compose: compose and ComposeError's module.

  The four new grants (terminal.control, floaty.control, floaty.raw, floaty.touch) are off by default, with Plugin Center switches in 11 languages (host 5bdb4d56a).
- Grant limit (Q170 (a)). A request may carry 128 host capabilities (host bcabd0452, Bun a33e26c). The plugin declares its limit in PluginInfo; a plugin that does not is cut at 64, the host keeping execution.control first. With every Bun grant on there are 72 grants plus execution.control.
- console. The 11 output functions and the 9 global console names write to the host console with console.control and to Bun's stdout / stderr without it (Q171 (a), host 6c2b19446). Output calls do not count toward the per-execution call limit, and one text is at most 8 MiB. console.build returns a local ConsoleConfigurator (52 members); show applies it with one configure call. rawInput resolves the host's input line and is cancelled with the execution; input evaluates it in the calling thread.
- toast. host.toast takes Rhino's arguments and dismissAll, and host.global carries toastLog / toastVerbose / toastInfo / toastWarn / toastError with their lower-case forms and isUiThread (false). The per-run limit of 4 toasts is gone; Android's toast queue decides (Q172 (a), host 2a948fa6a). The toast functions settle with ui.toast's result `{shown}` (Node settles with null).
- web. newWebSocket, the global newWebSocket and ByteString are local, over Bun's own WebSocket (Q174 (a)). The WebSocket handle's 24 Rhino members are local too.
- Handles (Q106 (a) / Q166 (a) / Q168 (a)). FloatyWindow / RawWindow / WebSocket / InjectableWebView / InjectableWebClient / ConsoleConfigurator and ComposeNode / ComposeSession / ComposeFloatyWindow / ComposeState / ComposeRef are compared member by member through their Bun handle types (runtime-policy.json `returnedObjects`, host cc3a55f97).
- Not portable (7 rows, as in Node): ui.layoutInflater (Rhino's Java LayoutInflater, Q169; use ui.inflate / ui.createView) and the internal names ui.__autojs6Tsx / __autojs6TsxFragment / __inflate__ / __widgets__ and the global __autojs6Tsx / __autojs6TsxFragment.

## Cases

`tools/api-coverage/device_bun_ui.py` (host 14943b3a6) runs the Node runtime's cases (`tools/nodejs/api/ui-family/cases.js` of P3.3, 22 cases) in Rhino, then in a Bun main script and in a Bun Worker of the same script.

- The Bun expressions see the client's namespaces and the family's globals from host.global.
- Three cases have no comparable Rhino value and are checked against fixed values: ui.emitter, ui.R and ui.layout (the content view needs a "ui" script in Rhino).
- toastLog has a Bun override: the toast functions settle with an object in Bun.
- web.newWebSocket.failure~ waits for the failure event of a socket to 127.0.0.1:9, then cancels it.
- Only cases without lasting effects run: windows, sessions and sockets are closed, the content window finishes, the toasts are short.

The denied run keeps floaty.control and shell.control on, turns the other 8 grants off and checks 13 entries:
- NOT_GRANTED with the missing grant for terminal.state / terminal.open (terminal.control, not implied by shell.control), floaty.rawWindow (floaty.raw), floaty.getClip (clipboard.control), console.rawInput / console.build().show (console.control), toast.dismissAll (ui.toast), ui.layout / ui.getStatusBarHeight (ui.layout) and compose.isAvailable (ui.compose);
- a floaty window that opens, moves and reaches its view with floaty.control alone;
- web.newInjectableWebView, whose view is inflated over floaty.control while ui.layout is off;
- web.ByteString, which stays local.

## Leftovers

- Grants: with every Bun grant on there are 72 grants plus execution.control, 73 of 128. Plugins built before Q170 still get 64.
- ui.layoutInflater is not-portable per Q169 (a), confirmed by the maintainer. Scripts use ui.inflate / ui.createView instead.
- In the matrix the floaty view routes show floaty.control (the grant of the method table). With ui.layout on they go through ui.layout instead. host-api.md describes the routing, and the denied run covers floaty.control alone.
- The policy rule java-prototype-objects is shadowed for 103 cells of the Bun column. The handle types cover these rows first, and the gate accepts them (as in the Node columns, P3.3).
