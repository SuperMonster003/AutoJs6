# OpenCV Java API 4.8.0

`opencv-java-4.8.0.aar` is the Java/API portion of the former
`opencv-4.8.0.aar`. It retains `classes.jar`, the Android manifest, resources,
`R.txt`, AAR metadata, and consumer ProGuard rules. It intentionally contains
no `jni/` entries.

The matching `libopencv_java4.so` runtime is distributed by the official
AutoJs6 OpenCV plugin. The SHA-256 of the retained upstream `classes.jar` is
`340976552fda3cce525021f0b072427cabf0aa1c786fb80cfc4a3a8105d90b3f`.

OpenCV 4.8.0 is distributed under the Apache License 2.0. AutoJs6 exposes the
corresponding attribution and license text in its Licenses screen.
