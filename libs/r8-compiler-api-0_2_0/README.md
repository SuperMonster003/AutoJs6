# Frozen R8 compiler API 0.2.0

This local wrapper contains the append-only AutoJs6 R8 compiler contract AAR frozen by
`AutoJs6-Plugin-R8-Compiler` G10. It retains protocol 1.0 compilation and adds the protocol 1.1
retrace capability. The checked-in byte identity is SHA-256
`ea1416913db1a93328c2fc8017f36a790e9e2ca04b8ad1c234d763da2d367424`.

The contract depends on the host's existing frozen `protocol-wire-api` classes. It is an
unpublished local integration artifact and must not be replaced by a source-project dependency or
interpreted as device acceptance.
