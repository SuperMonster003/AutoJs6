# Frozen R8 compiler API 0.1.0

This local wrapper contains the independent AutoJs6 R8 compiler contract AAR frozen by
`AutoJs6-Plugin-R8-Compiler` G1. The checked-in byte identity is SHA-256
`e9df49b7e49992615a15bc0af2372a4525f02b4a2a915a560ddab3128bb2f066`.

The contract depends on the host's existing `protocol-wire-api` classes. It is an unpublished
local integration artifact and must not be replaced by a source-project dependency or interpreted
as provider/device acceptance.
